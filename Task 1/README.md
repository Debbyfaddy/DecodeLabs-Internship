# Task 1: Data Cleaning & Preparation

1. # About the Project
This project is all about making dirty data clean and correct. I took a messy e-commerce file with errors and turned it into a perfect, clean file. This ensures the company has accurate numbers for its business decisions.  

2. # Tool Used
Microsoft Excel: I used Excel to find errors, delete double entries, fix wrong dates, and clean up the data.

3. # What I Cleaned and Fixed
1. Verified Order Uniqueness
I checked all the Order IDs thoroughly to ensure there were no double entries or repeated transactions.
This confirmed that every order in the dataset is unique and the total order count is perfectly accurate from the start.

4. # Renamed Empty Coupon Spaces
I did not delete the empty spaces in the coupon code column. Instead, I renamed them to give them a clear label (like "No Coupon" or "None").
Reason; Not every customer uses a coupon. Renaming them fills the empty gaps and makes the sheet look clean and professional.

5. # Fixed the Date Format
6. What I did: I changed all the different date styles into one clean format: YYYY-MM-DD.  Why: This helps the company sort the data easily by time without any errors. 

7. # Fixed the Price Numbers
I formatted all the unit prices and total prices to show exactly two numbers after the decimal point (like $10.50).
This makes sure the financial numbers are neat and correct.

8. # Final Results
Unique Orders: 100% Unique (0 duplicate orders found).
Date Format: 0% error rate (All dates look exactly the same).  
The data is now 100% ready for charts and reports!
